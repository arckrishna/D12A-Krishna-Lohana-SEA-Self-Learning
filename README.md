## 📚 Overview of Self-Learning Activities

This repository contains the complete, rigorous, and academically documented submission for the **Software Engineering and Architecture (SEA) Self-Learning Activity Track**. It synthesizes core software engineering principles, lifecycle management methodologies, requirements engineering techniques, and enterprise architectural governance into an integrated, industrial-grade framework.

### Summary of Modules

1. **[Activity 1: Comparison of Agile and DevOps](SEA_SelfLearning.md#1-comparison-of-agile-and-devops)**
   - Philosophical and structural comparison of Agile and DevOps.
   - Core values, 12 Agile principles, and the CALMS (Culture, Automation, Lean, Measurement, Sharing) framework.
   - Sprint lifecycle vs. DevOps continuous infinite-loop lifecycle.
   - Comprehensive comparative evaluation matrix across 10 engineering dimensions.
   - Practical synergy: How Agile small-batch iterations feed continuous automated CI/CD pipelines.

2. **[Activity 2: Case Study of JIRA and Asana in Real-World Projects](SEA_SelfLearning.md#2-case-study-of-jira-and-asana-in-real-projects)**
   - Deep architectural analysis of **Atlassian JIRA**: Epics, Stories, Tasks, Bug tracking, Scrum velocity burndown charts, and Kanban WIP limits.
   - Comprehensive exploration of **Asana**: Workspaces, Portfolios, Tasks, Subtasks, multi-perspective views (List, Board, Timeline/Gantt, Calendar), and rule-based workflow automation.
   - Real-world case study implementations based on enterprise application workflows.
   - Multi-criteria decision matrix and hybrid orchestration guidelines.

3. **[Activity 3: Writing Effective User Stories and Acceptance Criteria](SEA_SelfLearning.md#3-writing-effective-user-stories-and-acceptance-criteria)**
   - The anatomy of user stories using Ron Jeffries' 3 C's (*Card, Conversation, Confirmation*) and the Connextra template.
   - In-depth deconstruction of the **INVEST** principle (*Independent, Negotiable, Valuable, Estimable, Small, Testable*) with concrete evaluations.
   - Crafting verifiable Acceptance Criteria using **Behavior-Driven Development (BDD)** and Gherkin **Given–When–Then** scenarios.
   - Real enterprise domain examples: Dynamic keyless check-in, composite billing folios, and real-time dining dispatching.

4. **[Activity 4: Advanced Requirement Elicitation Techniques](SEA_SelfLearning.md#4-advanced-requirement-elicitation-techniques)**
   - The requirements iceberg: discovering tacit, latent, and operational requirements.
   - Rigorous breakdown of 6 elicitation techniques:
     - Structured, Semi-Structured & Unstructured Interviews
     - Workplace Ethnography & Contextual Inquiry (passive/active observation)
     - Joint Application Development (JAD) & Facilitated Workshops
     - Throwaway vs. Evolutionary Prototyping
     - Focus Groups & Brainstorming
     - Document Analysis & Reverse Engineering
   - Trade-off matrix: cost, stakeholder time commitment, risk of bias, and phase suitability.
   - Real-world field application case study.

5. **[Activity 5: Requirement Traceability Matrix (RTM)](SEA_SelfLearning.md#5-requirement-traceability-matrix-rtm)**
   - Theoretical foundation of requirements traceability (IEEE standards).
   - Traceability taxonomy: **Forward Traceability**, **Backward/Reverse Traceability**, and **Bidirectional Traceability**.
   - Complete, multi-column enterprise RTM table linking Business Requirements $\to$ Architectural Components $\to$ Code Files $\to$ Test Cases $\to$ Verification Status.
   - Systematic Change Impact Analysis methodology: Step-by-step impact propagation across backend, frontend, database, and regression test suites.

6. **[Activity 6: Enterprise Tools for Requirement Management](SEA_SelfLearning.md#6-tools-for-requirement-management)**
   - Critical evaluation of 5 industry-standard platforms:
     - **IBM Engineering Requirements Management DOORS** (formal modules, baselining, strict compliance like DO-178C/ISO 26262)
     - **Atlassian JIRA & Jira Product Discovery** (agile backlog tracking)
     - **Microsoft Azure DevOps / Azure Boards** (end-to-end work item linking with Git commits)
     - **Jama Connect** (living requirements, automated review center, FMEA risk analysis)
     - **Perforce Helix ALM** (unified requirements, test cases, and issue tracking)
   - Cross-platform comparative matrix and enterprise adoption challenges.

7. **[Overall Synthesis & Conclusion](SEA_SelfLearning.md#7-overall-integration--conclusion)**
   - End-to-end SDLC synthesis: Connecting Elicitation $\to$ User Stories $\to$ Requirement Management $\to$ Agile Sprint Execution $\to$ Traceability Matrix $\to$ DevOps CI/CD.
   - Formal academic references and textbook bibliography.
